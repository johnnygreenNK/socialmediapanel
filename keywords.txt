# Konfigurowalne wyszukiwania statystyk Gmaila.
# Format: klucz | Etykieta | zapytanie_gmail
# - linie zaczynające się od # to komentarze, puste linie pomijane
# - klucz musi być unikalny (bez spacji), bo trafia do JSON-a jako nazwa pola
# - Etykieta pojawi się w panelu i powiadomieniu Telegramu
# - zapytanie_gmail = pełna składnia Gmaila
#
# UWAGA do operatora `from:`:
# Gmail traktuje `from:paypal` jako "nadawca zawiera 'paypal' gdziekolwiek"
# (w adresie e-mail, nazwie wyświetlanej itd.) — to szersze i pewniejsze
# niż długa lista `from:paypal.com OR from:e.paypal.com OR ...`, która
# często czegoś nie łapie. Używamy więc krótkich form.
#
# Skopiuj ten plik do DATA_DIR/keywords.txt żeby edytować bez konfliktów git.
# Dla >2500 wiadomości pokazujemy ">2500" (szybciej); dla <2500 — dokładną.
